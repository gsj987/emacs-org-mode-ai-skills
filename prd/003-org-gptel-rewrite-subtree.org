#+TITLE: PRD 003 - Org Subheadline Rewrite via gptel Skill
#+STARTUP: overview

* Problem
Users need a fast way to rewrite content inside Org files by sending a selected
sub-headline subtree to gptel with a skill-guided prompt.
Current workflow is manual and does not provide structured context expansion
(e.g., include nearest enclosing headline or move to upper-level headline before send).

* Scope
- In scope:
  - Add a basic Org-mode integration flow to rewrite a selected sub-headline via gptel.
  - Provide an Embark-like entry action from point/headline selection.
  - Support context expansion modes before sending to gptel:
    - Use current nearest headline subtree.
    - Expand to upper-level headline (org-refile-like level jump).
  - Integrate with existing skill prompt mapping so rewrite is skill-constrained.
  - Return rewritten content in a predictable insertion/update flow.
  - Add tests for selection, context expansion, payload construction, and failure cases.
- Out of scope:
  - Full Embark package dependency and deep action framework integration.
  - Multi-file project-wide context assembly.
  - Autonomous headline selection without user trigger.
  - Non-Org major mode support.

* Constraints
- Technical constraints:
  - Must work in Org buffers with deterministic subtree boundary detection.
  - Must preserve Spec vs Run separation (no runtime mutation of skill spec files).
  - gptel integration should be through testable pure-data payload helpers where possible.
  - Errors must be explicit (no subtree at point, invalid level expansion, gptel unavailable).
  - Keep functions small and composable in =elisp/=.
- Process constraints:
  - Follow AGENTS workflow: PRD -> implementation -> tests -> test run -> README -> worklog.
  - Do not ship behavior that is not captured in this PRD.

* Expected Behavior
- Behavior 1:
  - User can trigger a rewrite action at an Org headline/sub-headline.
- Behavior 2:
  - System resolves a target subtree from point using selected context mode.
- Behavior 3:
  - Context mode "current" sends nearest headline subtree.
- Behavior 4:
  - Context mode "upper-level" expands to an ancestor headline based on selected level step.
- Behavior 5:
  - System builds a skill-guided gptel request payload from resolved subtree text.
- Behavior 6:
  - On success, rewritten content is inserted or replaces the target subtree per command contract.
- Behavior 7:
  - On failure, user gets actionable error messages without partial silent edits.
