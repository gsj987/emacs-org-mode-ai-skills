#+TITLE: PRD 017 - Org Code Block Execution and Autonomous Debug Workflow
#+STARTUP: overview

* Problem
Org workflows need first-class support for code block execution and debugging in-place across any org file, not only skill files. Current flow is not explicit enough for the full lifecycle: generation, execution, failure diagnosis, and iterative repair against user intent.

* Scope
- In scope:
  - Parse and identify executable code blocks within any org buffer/file context.
  - Execute supported code blocks with captured stdout/stderr/exit status.
  - Add autonomous debug workflow: rerun, inspect artifacts, and propose/apply targeted fixes.
  - Support a prompt-driven loop where generated code blocks are validated by actual execution and corrected when results fail or do not satisfy prompt constraints.
  - Surface execution metadata in org buffers for traceability.
- Out of scope:
  - Full replacement of Org Babel behavior.
  - Unbounded language runtime provisioning.
  - Remote/containerized execution orchestration.

* Constraints
- Technical constraints:
  - Execution must be explicit, sandbox-aware, and language-scoped.
  - Preserve reproducibility: inputs, env, and outputs should be recordable.
  - Debug flow must not silently mutate unrelated org content.
  - Auto-adjust must be bounded (attempt limit/time limit) and must preserve an auditable change history.
- Process constraints:
  - New execution/debug behavior requires ERT coverage.
  - Any supported language additions must include validation and tests.

* Expected Behavior
- Behavior 1:
  - Users can run a code block from any org file and receive structured result output.
- Behavior 2:
  - On failure (runtime error or unmet prompt expectation), debug view shows error context, command/runtime metadata, and rerun controls.
- Behavior 3:
  - System can iterate with explicit rerun and optional patch proposal/apply workflow, bounded by configured retry policy.
- Behavior 4:
  - Execution, evaluation, and debug events are logged for observability and later analysis.
