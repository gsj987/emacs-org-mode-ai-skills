#+TITLE: PRD 020 - Planner callback compatibility for non-thinking and thinking models
#+STARTUP: overview

* Problem
Planner runs can appear frozen when provider/model callback shape does not deliver planner JSON as a direct text callback chunk. Logs show HTTP 200 completion, but planner flow does not finalize.

* Scope
- In scope:
  - Harden planner request callback finalization in =org-ai-skills--request-planner-plan=.
  - Harden gptel callback text extraction so planner only consumes actual model output text (never echoed request prompt content from callback metadata).
  - Add planner-specific request stream control and default planner dispatch to streaming mode for OpenAI-compatible backends.
  - Support both callback shapes:
    - chunked/final text callbacks
    - terminal completion marker with payload in callback info data
  - Add regression ERT coverage for completion-marker paths.
  - Add one BDD scenario documenting planner compatibility expectation.
  - Update README behavior notes for planner callback handling.
- Out of scope:
  - Changing planner prompt contract or schema.
  - Changing execution-step callback behavior.
  - Backend/provider-specific adapters outside current planner callback path.

* Constraints
- Technical constraints:
  - Keep existing planner schema and parse validation unchanged.
  - Preserve streaming/chunk accumulation behavior.
  - Fail fast with explicit planner error when completion arrives without usable planner JSON payload.
  - Do not add fallback plan synthesis/workaround logic.
- Process constraints:
  - PRD-first change process.
  - Add tests in =tests/org-ai-skills-test.el= and =tests/bdd/=.

* Expected Behavior
- Behavior 1:
  - Planner run completes when callback JSON text arrives as normal text chunks.
- Behavior 2:
  - Planner run also completes when callback completion marker arrives and final JSON can be extracted from callback info payload.
- Behavior 3:
  - Planner run fails with explicit error (not freeze) when completion marker arrives without any parseable planner JSON.
