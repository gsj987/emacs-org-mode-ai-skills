#+TITLE: PRD 006 - Add Twitter Simplification Example Skill
#+STARTUP: overview

* Problem
Current examples include only one skill focused on expanding structure and detail.
To validate multi-skill composition scenarios (expand + simplify), we need a second
example skill that compresses content into a concise, post-ready form.

For practical testing, this skill should target tweet-ready constraints so users can
verify short-form output behavior in planner/step composition.

* Scope
- In scope:
  - Add a new skill spec file under =skills/= for simplifying content to tweet-ready form.
  - Define explicit constraints for concise and postable output.
  - Add ERT coverage that parses and validates the new skill spec.
  - Update README to mention the additional example skill and intended usage.
- Out of scope:
  - Changing runtime planner logic or parser contracts.
  - Adding platform API integration or automatic posting.

* Constraints
- Technical constraints:
  - Skill file must follow current org-skill parser contract (required tags/sections).
  - Skill spec files remain static/read-only at runtime.
  - Keep compatibility with existing tests and skill discovery ordering.
- Process constraints:
  - Follow AGENTS workflow: PRD -> implementation -> tests -> test run -> README -> worklog.

* Expected Behavior
- Behavior 1:
  - New skill file parses successfully with skill-id, tags, description, outputs/contracts/requirements.
- Behavior 2:
  - Skill intent clearly enforces concise, tweet-ready rewriting constraints.
- Behavior 3:
  - Existing and new tests pass without regressions.
